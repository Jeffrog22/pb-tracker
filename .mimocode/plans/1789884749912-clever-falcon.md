# Plan: Atualizar AGENTS.md — M2 split multi-volta

## Contexto

O usuário questionou se no modo SwimBase, em provas com mais de uma volta (ex.: 100m = 2x50m), o split deveria avançar automaticamente para o próximo atleta. Investigação no código confirmou:

- `recordM2Split()` (swimbase.js:1282) registra a volta do atleta selecionado mas **NÃO** chama `autoSelectNextM2()`. O atleta permanece selecionado para continuar registrando splits.
- `autoSelectNextM2()` (swimbase.js:1342) é chamado **somente** em `recordM2Final()` (linha 1338) quando nem todos os atletas terminaram.
- Se auto-avancasse após split, quebraria o registro do próximo atleta: ele perderia sua primeira volta porque estaria selecionado antes de começar a nadar, e `recordM2Split` verifica `raia.startedAt > 0` (que só é setado em `startMaster`).
- O usuário pode trocar de atleta manualmente clicando na row (`selectM2Atleta`), mas splits são sempre gravados no selecionado.
